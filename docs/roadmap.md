# Roadmap

Near term:

- Email delivery for team invites and weekly summaries.
- Password reset flow (self-service).
- File uploads for site-update photos (currently a count only).
- Pagination on list endpoints.
- CSRF tokens on top of the content-type check.

Later:

- PostgreSQL support via a connection string.
- Multi-organisation tenancy.
- Mobile app reusing the same API.
